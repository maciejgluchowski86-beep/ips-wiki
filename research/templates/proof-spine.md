# Proof spine

This file is maintained by the Professor. It is a small dependency graph for the active target, not a bureaucratic checklist and not a requirement to know the final proof in advance.

Revise it whenever the mathematical picture changes.

## Main target

State the current theorem or positive result as precisely as useful.

## Dependency graph

List the load-bearing claims, estimates, constructions, reductions, or literature facts separating the current state from the target.

For each item record, as useful:

- identifier;
- statement or role in the proof;
- dependencies;
- status: `verified`, `claimed`, `conditional`, `refuted`, or `open`;
- current owner: Professor, Student A, Student B, or outside session;
- decisive file pointer; and
- what would change if the item failed.

A table may be convenient, but no particular format is required.

## Current first unresolved edge

Identify the smallest or most informative unresolved part that currently controls progress. If several edges are genuinely independent, say so.

## Alternative routes still alive

Record only mathematically distinct alternatives worth remembering. Do not list every imaginable variant.

## Routes eliminated

Record routes whose failure would otherwise be expensive to rediscover, with pointers to the argument or counterexample that eliminated them.

## Revision note

When the spine changes materially, record briefly why the old decomposition was inadequate and what new information caused the revision.
