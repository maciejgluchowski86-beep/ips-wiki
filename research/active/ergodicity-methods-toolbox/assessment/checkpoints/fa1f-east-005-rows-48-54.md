# FA-1f / East audit checkpoint 005: rows 48--54

Date: 2026-08-17

Crash-safe intermediate checkpoint for the Professor-owned FA-1f/East applicability audit.

| # | Method | Rating | Target interface and ruling |
|---|---|---|---|
| 48 | Foster--Lyapunov plus Harris small-set recurrence | X | The checked criterion needs recurrence to a set carrying a uniform minorization and then yields uniqueness/convergence in the relevant class. Hard infinite-volume FA has a closed all-ones trap and no plausible uniform small set in the product topology; a local screened reduction would first have to be constructed. That screen, not Harris, would carry the target-level mathematics. Pointer: `foster-lyapunov-harris-geometric-ergodicity.md`, limitations. |
| 49 | Infinite-dimensional Harris for Levy SPDEs | N | The source manufactures a compact small set using smoothing into a stronger topology plus strong Feller/irreducibility. FA has discrete graphical noise with no compact regularization analogue and multiple closed classes. Pointer: `infinite-dimensional-harris-levy-spde.md`. |
| 50 | Regeneration at a particle-collapse atom | N | Literal collapse of an infinite spin configuration to one renewal atom has probability zero/does not fit the FA state space, while global coalescence is contradicted by the trap. The general lesson 'find an exact atom' is too unspecific to be a bridge. Pointer: `particle-collapse-regeneration.md`, limitations. |
| 51 | Front regeneration and renewal times | B | **High-priority spatial architecture.** The source's key move is not merely tracking a front but defining successful candidate times at which old particles can never re-enter the future front dynamics, so the post-regeneration graphical future is fresh. This matches the exact gap left by the closed FA finite-seed programme. For the Bernoulli quench, the required adaptation is a *two-sided local regeneration screen*: around a fixed observation interval, find left/right vacancy-front renewal structures that with probability tending to one isolate the interval from pre-regeneration exterior history for a macroscopic remaining time. Once isolated, the known positive FA gap/constraint-domination can relax the interior. This bypasses the conservative coefficient-transfer obstruction entirely. Pointer: `front-regeneration-renewal-times.md`; finite-seed `proof-spine.md`; `east-distinguished-zero-screening.md`. Explicit bridge lemma to be stated in final shortlist. It is even more directly promising for the finite-seed problem. |
| 52 | Competition-interface regeneration | C | The useful feature is *approximate* graphical restart of a localized interface rather than exact regeneration. FA quench has no single localized competition interface, so an adaptation would first need to manufacture the same two-sided vacancy screen as row 51. Once that exists, row 51 is the cleaner template. Pointer: `competition-interface-regeneration.md`. More relevant to finite-seed/front formulations. |
| 53 | Survival-conditioned renewal points | C | Exact fresh graphical futures at random ancestor points are a strong precedent for regeneration under a conditioning event, but FA has no supercritical survival-conditioned ancestor process playing the same role. A vacancy renewal point would have to be newly constructed; row 51 states that target more naturally. Pointer: `survival-conditioned-renewal-multitype-contact.md`. |
| 54 | Essential hitting times / almost-subadditive regeneration | C | This is useful if one first has a persistent vacancy/front process and wants deterministic growth speed despite imperfect regeneration. Growth of a vacancy-influenced region could be an ingredient in a screen theorem, especially finite seed, but almost-subadditivity does not itself erase local memory or identify the quench limit. Pointer: `essential-hitting-time-almost-subadditive-growth.md`. |

## Batch conclusion

`front-regeneration-renewal-times` is the first toolbox method whose **source architecture directly matches an obstruction named by the closed FA programme**. It joins the provisional B shortlist. Competition-interface and survival-conditioned renewals are supporting templates, not independent target-level architectures at present.
