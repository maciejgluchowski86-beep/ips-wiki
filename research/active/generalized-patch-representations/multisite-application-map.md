# Concrete application map for the multi-site patch extension

Date: 2026-08-19

This note answers one question only: which named models become available once simultaneous multi-site flips are allowed, split by the cost of the patch construction. It is exploratory. Nothing here asserts model-specific patch positivity unless stated.

## A. Cheap tier: disjoint or uniformly bounded non-overlap block dynamics

The genuinely standard examples here are mostly block samplers rather than translation-invariant physical lattice gases. This is because physical nearest-neighbour moves usually use overlapping edges.

### A1. Continuous-time heat-bath block dynamics for the Ising model

Literature status: standard. Continuous-time block dynamics assigns a Poisson clock to each block and, when it rings, resamples the whole block from the Gibbs conditional distribution given the exterior. See, e.g., Blanca--Caputo--Chen--Parisi--Stefankovic--Vigoda, *Block Factorization of the Relative Entropy via Spatial Mixing* (CMP 2022), and the standard block-dynamics discussion in critical Ising mixing work.

If the chosen blocks form a partition, then a resampling changes an arbitrary subset of spins inside one block but never touches another block. Therefore the disjoint-block reduction applies directly after decomposing each block transition by its symmetric-difference flip set.

What the patch statement gives:

- exact one-block patch representation for monomial semigroup values;
- local hidden state space of size `2^{|Q|}` for a block `Q`;
- a finite transfer-matrix formulation of bulk patch positivity;
- multi-affine end factors on the terminal spins of `Q`;
- centered-moment order if all centered end coefficients are nonnegative.

This is mainly a proof-of-concept application: block dynamics already has strong coupling, entropy-factorization, and spectral-independence tools, so a patch theorem would not by itself improve known mixing results.

### A2. Disjoint-clique/block dynamics for hard-core type models

Literature status: block dynamics on hard-core discretizations and disjoint cliques is standard in algorithmic sampling; see Friedrich--Goebel--Krejca--Pappik, *A Spectral Independence View on Hard Spheres via Block Dynamics* (2021/2022).

Encoding occupation by binary spins, a whole clique/block update can change several occupation bits simultaneously. If the update blocks are disjoint, the same one-block patch construction applies. Invalid hard-core configurations can be given zero transition rates; starting from the admissible state space the process stays there.

What the patch statement gives:

- exact block-patch representation on occupation monomials;
- finite-dimensional block positivity tests;
- a possible centered-moment comparison theorem on the admissible sector if end-block centered coefficients are positive.

Again, this is more a clean demonstration of scope than the most promising new application.

## B. Hyperpatch tier: overlapping local moves

This is where the important new physical models live. The deterministic-envelope record is needed: expose all sites in the update block/target envelope as patch boundaries while hiding the sign-carrying routing/post-source state. Hyperpatches are connected components generated by shared selected records and shared omitted clocks.

### B1. Kawasaki dynamics for the Ising lattice gas

Standard Kawasaki dynamics exchanges occupations across nearest-neighbour bonds, with Metropolis/heat-bath rates depending on the local energy change. It is the canonical conservative Ising/lattice-gas dynamics. See, e.g., the extensive metastability literature on the Ising lattice gas under Kawasaki dynamics and the zero-temperature work of Gois--Landim.

Cost: full envelope hyperpatch machinery. Nearest-neighbour bonds overlap, and nonconstant rate modes produce opposite-sign dual outcomes with different actual routing of activity across the bond.

What the patch statement gives:

- exact hyperpatch representation of occupation monomial expectations;
- cancellation of environmental-rate modes before absolute values, instead of splitting the `stay` and `move` dual branches globally;
- a positive patch-variation majorant candidate for connected density correlations/oscillations if one takes absolute values only after hyperpatch averaging.

What it does **not** immediately give: the paper's pure-death comparison or unique-invariant-law theorem. Kawasaki conserves particle number, so any convergence statement would have to be sectorwise and would require new arguments.

### B2. Speed-change exclusion process

A standard speed-change exclusion process exchanges occupations across bond `(z,z+1)` at a strictly positive local rate `c_z(eta)` depending on a finite neighbourhood, typically not on the two endpoint spins themselves. This is exactly the clean environmental-rate version of the Kawasaki calculation. See the literature on speed-change exclusion/stochastic lattice gases.

Cost: envelope hyperpatches.

What the patch statement gives:

- an exact hyperpatch representation in which different multilinear modes of the local speed are averaged along the same connected bond-history component;
- genuine cancellation relative to the raw absolute signed dual whenever the same envelope carries opposite-sign routing branches;
- a natural setting for the patch-variation kernel `R_t`, potentially giving sharper covariance/oscillation bounds than the raw absolute-FK branching majorant.

This is probably the cleanest nontrivial exchange model for proving the hyperpatch theorem before tackling constrained rates.

### B3. Kob--Andersen kinetically constrained lattice gas

Kob--Andersen (KA) models are the best-known kinetically constrained lattice gases: hard-core particles perform Kawasaki-type nearest-neighbour jumps only when a local vacancy constraint is satisfied before/after the jump. Blondel--Toninelli explicitly describe KCLG as exclusion systems with Kawasaki-type dynamics, with KA as the principal class.

Cost: envelope hyperpatches. Jump edges overlap, and the kinetic constraint creates nonconstant environmental modes.

What the patch statement gives:

- the first direct patch representation for a conservative KCM analogue, rather than a single-site KCSM;
- exact averaging of the signed constraint expansion across successive constrained jumps inside a hyperpatch;
- a possible route to centered occupation-moment inequalities or correlation majorants if hyperpatch positivity/end-cone positivity can be verified.

This is the most natural application for the intended KCSM audience. It genuinely enlarges the paper's model class rather than merely changing the sampler.

### B4. Facilitated exclusion process / facilitated TASEP / symmetric FEP

The facilitated exclusion process is a one-dimensional conservative constrained system in which a particle jumps to a neighbouring vacancy only when the other neighbouring site is occupied. The literature includes facilitated TASEP (Baik--Barraquand--Corwin--Suidan) and symmetric/asymmetric FEP mixing results (Ayre--Chleboun).

Cost: envelope hyperpatches, but probably the cheapest serious hyperpatch application because the geometry is one-dimensional and the constraint is nearest-neighbour.

What the patch statement gives:

- exact hyperpatch representation for occupation moments under a conservative facilitated dynamics;
- local cancellation of the facilitation-mode expansion along overlapping bond moves;
- a realistic first test for whether a nontrivial hyperpatch positivity or centered-end positivity criterion can hold in a conservative KCM.

Unlike KA, the one-dimensional/oriented geometry may permit an explicit finite-state description of common hyperpatch shapes.

### B5. Pair-contact process with diffusion (PCPD)

The PCPD is the standard binary reaction-diffusion model combining single-particle diffusion with pair reactions `2A -> 3A` and `2A -> 0`. Pair annihilation flips two occupied sites simultaneously, while diffusion is a nearest-neighbour exchange. The model has a long literature because the nature of its absorbing-state critical behaviour has been controversial.

Cost: envelope hyperpatches. The pair annihilation and diffusion supports overlap throughout the lattice.

What the patch statement gives:

- exact representation of density and higher occupation moments for a model genuinely excluded by the single-site generator;
- delayed averaging between diffusion-routing and pair-reaction branches inside connected spacetime components;
- if positivity fails, still a candidate patch-variation majorant for moment/correlation estimates.

A positivity theorem here would be interesting, but there is currently no reason to expect it; the model should be treated as a difficult application, not an easy showcase.

### B6. Annihilating random walks with pairwise immigration / annihilating walks with pair deposition

A standard exactly solvable family has nearest-neighbour random walks which annihilate on collision together with pairwise immigration/deposition on neighbouring sites. In the binary occupation encoding, pair immigration is a simultaneous two-site toggle and the jump-annihilation move is a two-site update conditional on the source being occupied. Garrod--Poplavskyi--Tribe--Zaboronski study such annihilating systems and prove Pfaffian structure for related models.

Cost: envelope hyperpatches.

What the patch statement gives:

- an exact hyperpatch representation for a pair-update model where independent exact formulas already exist;
- therefore an excellent validation/calibration example for the construction and for any proposed hyperpatch contribution formulas;
- little immediate novelty unless the patch representation exposes a new inequality not visible from the Pfaffian solution.

### B7. Domino/lozenge tiling Glauber dynamics and related local-flip interface chains

Local Glauber dynamics for domino or lozenge tilings changes several edge-occupation variables in one elementary face/vertex flip. Such local flip chains are standard and have an extensive mixing literature; e.g. Laslier--Toninelli for domino/lozenge Glauber dynamics and recent work on lozenge tilings.

Cost: envelope hyperpatches **plus a constrained-state-space layer**. In the natural binary encoding the spins are edge occupancies constrained to be a perfect matching/tiling, rather than arbitrary elements of `{0,1}^Lambda`.

What the patch statement could give after that extra encoding step:

- an exact representation for edge-occupation correlations under local tiling flips;
- a cancellation majorant for covariance/mixing estimates.

This is a mathematically real extension, but it is not the first application to pursue because the constrained state space adds work unrelated to the multi-site-flip issue itself.

## C. Calibration case: simple exclusion

SSEP itself is in the new multi-site scope because a nearest-neighbour particle move is an exchange of two occupation bits. However, for monomials its dual is already the positive exclusion process. Thus the hyperpatch representation collapses to ordinary positive duality and gains no cancellation.

This is useful as a zero-obstruction check, not as a substantive application.

## Ranking for the eventual principal report

For a paper-facing application section, the most relevant order is likely:

1. **Facilitated exclusion process**: simplest genuinely new conservative KCM, one-dimensional and likely tractable.
2. **Kob--Andersen KCLG**: strongest conceptual extension of the KCSM story.
3. **Speed-change exclusion**: cleanest generic nontrivial hyperpatch algebra.
4. **Kawasaki Ising lattice gas**: canonical named conservative dynamics, but likely harder and no pure-death convergence analogue.
5. **PCPD**: genuinely new reaction-diffusion scope, but difficult positivity prospects.
6. **Pfaffian annihilating/pair-deposition models**: excellent exact benchmark.
7. **Tiling Glauber dynamics**: interesting but requires an extra constrained-state-space extension.

The disjoint-block Ising/hard-core examples are valuable for proving and illustrating the block theorem, but they are less compelling as the motivating application because existing block-dynamics methods are already very strong.
