# Student G 010g checkpoint: exact filtered tail-shift interface

**Status:** intermediate durable checkpoint for Assignment 010.  This identifies exactly how the connected coefficient meets the old spatial-memory interface.  It does **not** prove equivalence to the stopped bare tail-shift theorem; the connected test class is much narrower.

## 1. Prefix marginal and boundary covariance

Retain the notation of 010e.  For a function `f` on the first `N` sites put

\[
A_N(f):=\pi_{N+1}(f),
\qquad
C_N(f):=\pi_{N+1}(Y_{N+1}f).
\]

Thus `A_N` is the left `N`-site marginal of `pi_{N+1}`.  Define the one-step marginal discrepancy

\[
\boxed{\delta_N:=A_N-\pi_N.}
\tag{1}
\]

The exact stationarity elimination in 010e gives

\[
\boxed{C_N=A_NR_N,}
\qquad
R_N=(dI-gL_N)(rI-L_N)^{-1},
\qquad r=1+b.
\tag{2}
\]

Since `R_N` is a rational function of `L_N`,

\[
\pi_NR_N=\frac dr\pi_N=-\varepsilon\pi_N,
\qquad
\varepsilon=\frac9{10000}.
\tag{3}
\]

Also `pi_N Q_N=0`.  Therefore

\[
\boxed{\pi_NR_NQ_N=0.}
\tag{4}
\]

## 2. Every connected coefficient is a filtered tail-shift pairing

Define the pre-resolvent connected orbit recursively by

\[
f_1:=J_1 1=Y_1,
\]

\[
\boxed{f_N:=J_NQ_{N-1}f_{N-1}
=Y_NQ_{N-1}f_{N-1},\qquad N\ge2.}
\tag{5}
\]

Then, for `N>=1`,

\[
\begin{aligned}
c_{N+1}
&=\pi_{N+1}J_{N+1}Q_Nf_N\\
&=C_N(Q_Nf_N)\\
&=A_NR_NQ_Nf_N.
\end{aligned}
\]

Using `(4)`,

\[
\boxed{
 c_{N+1}
 =\delta_N\!\left(R_NQ_Nf_N\right).
}
\tag{6}
\]

This is exact at every depth.

Thus the invariant projection removed in `Q_N` has not secretly reappeared as an unrestricted tail-shift requirement.  The spatial discrepancy `delta_N` is tested only against the special function

\[
\boxed{\mathcal T_N:=R_NQ_Nf_N,}
\tag{7}
\]

which is generated by the connected orbit and carries the positive-frequency high-pass factor `R_N`.

## 3. The marginal discrepancy has an exact local source equation

The first stationarity block identity of 010e is

\[
A_N(L_N+cP_N)+C_NP_N=0,
\tag{8}
\]

where `P_N` is the canonical projection onto `Y`-monomials containing the old right boundary site `N`.  Insert `(2)` and use `pi_NL_N=0`:

\[
\boxed{
\delta_NL_N
=-A_N(cI+R_N)P_N.
}
\tag{9}
\]

The rational factor simplifies completely.  Indeed

\[
\begin{aligned}
cI+R_N
&=\frac{c(rI-L_N)+dI-gL_N}{rI-L_N}\\
&=\frac{(cr+d)I-(c+g)L_N}{rI-L_N}.
\end{aligned}
\]

At every parameter point, not only `P_*`,

\[
cr+d=B,
\qquad
c+g=B.
\]

Hence

\[
\boxed{
 cI+R_N
 =B(I-L_N)(rI-L_N)^{-1},
}
\tag{10}
\]

and therefore

\[
\boxed{
\delta_NL_N
=-B\,A_N(I-L_N)(rI-L_N)^{-1}P_N.
}
\tag{11}
\]

So `delta_N` is a zero-frequency Poisson response to a source localized at the right boundary, exactly as in the earlier stationary boundary-response work.  Equation `(6)` specifies the narrower test on which Assignment 010 needs that response.

## 4. Comparison with the stopped F013/F014 interface

Student F013 proves that the unrestricted remote norm of the first signed insertion defect is, away from `m_0=0`, equivalent up to exponentially localized covariance to the bare one-step tail-shift norm

\[
\Delta_M
=\|\theta^M\mu-\theta^{M-1}\mu\|_{\rm TV}.
\]

F014 likewise shows that the zero-frequency part of the recombined two-insertion defect retains the unrestricted two-step marginal discrepancy `delta_N^(2)` after all fixed-suffix and light-cone terms are removed.

Equation `(6)` is different in a precise sense.  Assignment 010 asks only for the sequence of pairings

\[
\delta_N(\mathcal T_N),
\qquad
\mathcal T_N=R_NQ_Nf_N,
\]

not for

\[
\sup_{\|f\|_\infty\le1}|\delta_N(f)|
\]

on arbitrary remote observables.

Therefore the connected route has **not** been proved equivalent to F013/F014's stopped zero-frequency object.  To establish such a negative equivalence one would need a new theorem showing that the connected test family `{mathcal T_N}` norms the relevant remote sigma-fields, or at least dominates the old `Delta_M`; no such statement follows from `(6)`--`(11)`.

Conversely, `(6)` shows exactly what remains to prove on this interface if a full orbit contraction is unavailable: a filtered tail-shift estimate

\[
\boxed{
|\delta_N(\mathcal T_N)|\le Cq^N,
\qquad q<1,
}
\tag{12}
\]

or any summable substitute strong enough for `(T)`.  This is strictly narrower than bare tail-shift agreement and retains the exact connected positive-frequency factor.
