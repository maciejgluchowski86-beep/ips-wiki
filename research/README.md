# Research workspace

This directory contains non-rendered working material for the autonomous research programme.

It is scratch/research space, not part of the public wiki. Tentative claims, failed calculations, partial proofs, exploratory literature notes, and computational work belong here rather than under `docs/`.

For each new active programme:

1. create a branch `research/<short-programme-slug>`;
2. create `research/active/<short-programme-slug>/`;
3. start from the templates in `research/templates/` when useful;
4. keep long mathematics in durable files rather than compressing it into chat handoffs; and
5. keep the programme's `state.md` current enough that either persistent researcher can re-enter the problem quickly.

The templates are starting points, not mandatory response forms.
