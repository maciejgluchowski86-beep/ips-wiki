\section{Residual signed variation and exact coarsening characterization}
\label{sec:coarsening}

The previous sections show that complete interior averaging can restore $L^1$, while the canonical raw marked integrand can have infinite first moment. The distinction admits an exact formulation. The relevant invariant is not which types of marks remain random. It is the amount of signed variation which remains after the discarded variables have been averaged.

\subsection{The exact invariant}

\begin{theorem}[Residual signed variation characterization]
\label{thm:residual-characterization}
Let $\cT$ be a countable set of retained skeleton labels. For every $\tau\in\cT$, let $(\cM_\tau,\mathcal F_\tau)$ be a measurable raw mark space, let $\nu_\tau$ be a finite positive measure, let $R_\tau\in L^1(\nu_\tau)$, and define the finite signed measure
\begin{equation*}
  \mu_\tau=R_\tau\nu_\tau.
\end{equation*}
Let
\begin{equation*}
  \cC_\tau:\cM_\tau\to\overline{\cM}_\tau
\end{equation*}
be measurable, and put
\begin{equation*}
  \overline\mu_\tau
  =
  (\cC_\tau)_\#\mu_\tau,
  \qquad
  \overline\nu_\tau
  =
  (\cC_\tau)_\#\nu_\tau.
\end{equation*}
Then, for every $\tau$,
\begin{equation}
  \frac{d\overline\mu_\tau}{d\overline\nu_\tau}
  (\cC_\tau(\omega))
  =
  \E_{\nu_\tau}
  \br{
    R_\tau
    \mid
    \sigma(\cC_\tau)
  }(\omega)
  \quad
  \nu_\tau\text{-a.e.},
  \label{eq:conditional-pushforward-density}
\end{equation}
and hence
\begin{equation}
  \boxed{
  \norm{(\cC_\tau)_\#\mu_\tau}_{\TV}
  =
  \int_{\cM_\tau}
  \abs{
    \E_{\nu_\tau}
    \br{R_\tau\mid\sigma(\cC_\tau)}
  }
  d\nu_\tau.
  }
  \label{eq:residual-TV-identity}
\end{equation}
The quantity in~\eqref{eq:residual-TV-identity} is intrinsic: it is independent of the chosen positive reference representation $\mu_\tau=R_\tau\nu_\tau$.

Assume now that the skeleton label $\tau$ itself is retained. Let $\pi$ be any full-support probability mass function on $\cT$, and for every $\tau$ let $Q_\tau$ be a probability measure dominating $\overline\mu_\tau$. If
\begin{equation}
  Y
  =
  \frac1{\pi(S)}
  \frac{d\overline\mu_S}{dQ_S}(U),
  \qquad
  S\sim\pi,
  \quad
  U\mid\{S=\tau\}\sim Q_\tau,
  \label{eq:canonical-coarsened-weight}
\end{equation}
is the canonical coarsened importance sampler, then
\begin{equation}
  \boxed{
  \E\abs Y
  =
  \sum_{\tau\in\cT}
  \norm{\overline\mu_\tau}_{\TV}.
  }
  \label{eq:coarsened-L1-sum}
\end{equation}
Consequently
\begin{equation}
  \boxed{
  Y\in L^1
  \quad\Longleftrightarrow\quad
  \sum_{\tau\in\cT}
  \int
  \abs{
    \E_{\nu_\tau}
    \br{R_\tau\mid\sigma(\cC_\tau)}
  }
  d\nu_\tau
  <\infty.
  }
  \label{eq:exact-L1-characterization}
\end{equation}

More generally, let $\widetilde Y\in L^1$ be any estimator, possibly with additional auxiliary randomness, such that after the retained skeleton and retained coarsened state are exposed its conditional barycenter equals the canonical signed density in~\eqref{eq:canonical-coarsened-weight}. Then
\begin{equation}
  \E\abs{\widetilde Y}
  \geq
  \sum_{\tau\in\cT}
  \norm{\overline\mu_\tau}_{\TV}.
  \label{eq:coarsened-jensen-lower}
\end{equation}
Thus the right side of~\eqref{eq:coarsened-L1-sum} is the minimum possible first moment in the conditional-barycenter class associated with the fixed skeleton-preserving coarsening scheme. If the sum is infinite, no $L^1$ estimator in that class exists; if it is finite, the canonical sampler~\eqref{eq:canonical-coarsened-weight} attains it.

If the skeleton label itself is also coarsened, the same one-measure identity~\eqref{eq:residual-TV-identity} applies after enlarging the raw state to include the skeleton label, but the per-skeleton sum~\eqref{eq:coarsened-L1-sum} need not be the correct invariant.
\end{theorem}

\begin{proof}
Because $\mu_\tau\ll\nu_\tau$, one has $\overline\mu_\tau\ll\overline\nu_\tau$. Let
\begin{equation*}
  \overline R_\tau
  =
  \frac{d\overline\mu_\tau}{d\overline\nu_\tau}.
\end{equation*}
For every measurable $B\subseteq\overline{\cM}_\tau$,
\begin{align*}
  \int_{\cC_\tau^{-1}(B)}R_\tau\,d\nu_\tau
  &=
  \mu_\tau(\cC_\tau^{-1}(B))\\
  &=
  \overline\mu_\tau(B)\\
  &=
  \int_B\overline R_\tau\,d\overline\nu_\tau\\
  &=
  \int_{\cC_\tau^{-1}(B)}
  \overline R_\tau(\cC_\tau(\omega))
  \,d\nu_\tau(\omega).
\end{align*}
The function $\overline R_\tau\circ\cC_\tau$ is $\sigma(\cC_\tau)$-measurable, so this is precisely the defining property of the conditional expectation in~\eqref{eq:conditional-pushforward-density}. Therefore
\begin{align*}
  \norm{\overline\mu_\tau}_{\TV}
  &=
  \int_{\overline{\cM}_\tau}
  \abs{\overline R_\tau}
  \,d\overline\nu_\tau\\
  &=
  \int_{\cM_\tau}
  \abs{\overline R_\tau\circ\cC_\tau}
  \,d\nu_\tau,
\end{align*}
which proves~\eqref{eq:residual-TV-identity}.

For~\eqref{eq:coarsened-L1-sum}, condition on $S$ and use the Radon--Nikodym identity:
\begin{align*}
  \E\abs Y
  &=
  \sum_{\tau\in\cT}
  \pi(\tau)
  \int
  \frac1{\pi(\tau)}
  \abs{\frac{d\overline\mu_\tau}{dQ_\tau}}
  dQ_\tau\\
  &=
  \sum_{\tau\in\cT}
  \norm{\overline\mu_\tau}_{\TV}.
\end{align*}
This proves necessity and sufficiency for the canonical sampler.

Finally, if $\widetilde Y$ has the same coarsened conditional barycenter, conditional Jensen on each retained skeleton/coarsened-state fiber gives~\eqref{eq:coarsened-jensen-lower}. The canonical sampler has equality, so the lower bound is sharp.
\end{proof}

We call
\begin{equation}
  V_\tau(\cC_\tau)
  :=
  \norm{(\cC_\tau)_\#\mu_\tau}_{\TV}
  \label{eq:residual-variation-def}
\end{equation}
the \emph{residual signed variation}. If $\cC_1$ is coarser than $\cC_2$, so
\begin{equation*}
  \sigma(\cC_1)
  \subseteq
  \sigma(\cC_2),
\end{equation*}
then the tower property and conditional Jensen give
\begin{equation}
  V_\tau(\cC_1)
  \leq
  V_\tau(\cC_2).
  \label{eq:residual-monotonicity}
\end{equation}
The endpoints are
\begin{equation}
  V_\tau(\Id)
  =
  \norm{\mu_\tau}_{\TV},
  \qquad
  V_\tau(\mathrm{const})
  =
  \abs{\mu_\tau(\cM_\tau)}.
  \label{eq:residual-endpoints}
\end{equation}
Thus cancellation before absolute values is exactly the reduction
\begin{equation*}
  \norm{\mu_\tau}_{\TV}
  -
  V_\tau(\cC_\tau).
\end{equation*}

\subsection{The retained variable type is not the invariant}

The next two examples are abstract signed-measure examples. They are not asserted to arise from the quadratic-Hessian raw measures.

\begin{example}[The entire Gaussian configuration may survive]
\label{ex:full-gaussian-small-piece}
For $n\geq1$, let
\begin{equation*}
  \Omega_n=\R^n,
  \qquad
  \nu_n=\gamma_n,
\end{equation*}
where $\gamma_n$ is standard Gaussian measure, and put
\begin{equation*}
  R_n(z)
  =
  2^{-n}+\operatorname{sgn}(z_1).
\end{equation*}
Then
\begin{equation*}
  \mu_n(\Omega_n)=2^{-n},
  \qquad
  \norm{\mu_n}_{\TV}=1.
\end{equation*}
Thus the constant coarsening is summable while the identity coarsening is not.

Choose $\delta_n>0$ so that the symmetric slab
\begin{equation*}
  A_n
  =
  \set{z:\abs{z_1}\leq\delta_n}
\end{equation*}
has $\gamma_n(A_n)=2^{-n}$. Define
\begin{equation*}
  \cC_n(z)
  =
  \begin{cases}
    (1,z),&z\in A_n,\\
    (0,*),&z\notin A_n.
  \end{cases}
\end{equation*}
On $A_n$ the complete vector $(z_1,\ldots,z_n)$ is retained. By symmetry,
\begin{equation*}
  \int_{A_n}\operatorname{sgn}(z_1)d\gamma_n
  =
  \int_{A_n^c}\operatorname{sgn}(z_1)d\gamma_n
  =0.
\end{equation*}
Hence
\begin{equation}
  V_n(\cC_n)
  =
  2^{-n}
  +
  2^{-n}(1-2^{-n})
  <
  2^{1-n}.
  \label{eq:gaussian-small-piece-TV}
\end{equation}
Therefore
\begin{equation*}
  \sum_nV_n(\cC_n)<\infty,
\end{equation*}
even though every Gaussian coordinate survives exactly on a nonnull piece of the state space.
\end{example}

\begin{example}[Retaining only time can fail]
\label{ex:time-only-fails}
Let
\begin{equation*}
  \Omega_n=(0,1)\times\R^n,
  \qquad
  \nu_n=ds\otimes\gamma_n,
\end{equation*}
and define
\begin{equation*}
  R_n(s,z)
  =
  2^{-n}+h(s),
  \qquad
  h(s)
  =
  \begin{cases}
    1,&0<s<1/2,\\
    -1,&1/2<s<1.
  \end{cases}
\end{equation*}
Again
\begin{equation*}
  \mu_n(\Omega_n)=2^{-n},
\end{equation*}
so complete averaging is summable. Retain only time,
\begin{equation*}
  \cC_n(s,z)=s.
\end{equation*}
Every Gaussian coordinate is averaged out, but
\begin{equation*}
  \E_{\nu_n}[R_n\mid s]
  =
  2^{-n}+h(s),
\end{equation*}
and therefore
\begin{equation}
  V_n(\cC_n)
  =
  \int_0^1\abs{2^{-n}+h(s)}ds
  =1.
  \label{eq:time-only-TV}
\end{equation}
Thus
\begin{equation*}
  \sum_nV_n(\cC_n)=\infty.
\end{equation*}
The failure is residual sign variation visible as a function of time; no Gaussian randomness survives at all.
\end{example}

These examples rule out any characterization based only on which named coordinates are retained.

\subsection{Sparse full-state retention in the C-prime regime}

\begin{proposition}[Sparse full-state retention at a fixed target]
\label{prop:sparse-raw-retention}
Fix $0<\alpha<1$, $T>0$, $\lambda\in\R$, and $\phi\in C^{2+\alpha}(\Torus)$. Put
\begin{equation*}
  M=\norm{P_\cdot\phi''}_{X_{\alpha,T}},
  \qquad
  a=\abs\lambda C_{\cD}(\alpha,T)M,
\end{equation*}
and assume $4a<1$. Fix one observation point
\begin{equation*}
  (t,x)\in[0,T]\times\Torus.
\end{equation*}
Then there exists a nonconstant skeleton-preserving coarsening family
\begin{equation*}
  \{\cC_\tau^{t,x}:\tau\in\cT\}
\end{equation*}
which is allowed to depend on this fixed target, such that
\begin{equation}
  \sum_{\tau\in\cT}
  \norm{(\cC_\tau^{t,x})_\#\mu_\tau^{t,x}}_{\TV}
  <\infty.
  \label{eq:sparse-retention-sum}
\end{equation}
For every non-leaf skeleton with nonzero raw signed measure, $\cC_\tau^{t,x}$ retains the entire raw marked state on a measurable set of strictly positive total-variation measure. Hence the Gaussian/Hermite, branch-time, and descendant coordinates remain observable in the retained state on that set.

The proposition is pointwise in $(t,x)$. It does not construct one target-independent coarsening family which works simultaneously for all observation points, and it does not assert that every retained coordinate changes the numerical estimator value.
\end{proposition}

\begin{proof}
Theorem C-prime gives
\begin{equation*}
  \sum_{\tau\in\cT}
  \abs{F_\tau(t,x)}<\infty.
\end{equation*}
Each finite non-leaf raw measure is absolutely continuous with respect to a reference law containing continuous Gaussian and time coordinates, so its total-variation measure is nonatomic. Choose positive numbers $\varepsilon_\tau$ with
\begin{equation*}
  \sum_\tau\varepsilon_\tau<\infty.
\end{equation*}
For every nonzero non-leaf measure choose a measurable set $A_\tau$ such that
\begin{equation*}
  0<
  \abs{\mu_\tau^{t,x}}(A_\tau)
  \leq
  \varepsilon_\tau.
\end{equation*}
Define $\cC_\tau^{t,x}$ to be the identity on $A_\tau$ and to collapse $A_\tau^c$ to a single point; for the leaf use the constant map. The two images are disjoint, so
\begin{align*}
  V_\tau(\cC_\tau^{t,x})
  &=
  \abs{\mu_\tau^{t,x}}(A_\tau)
  +
  \abs{\mu_\tau^{t,x}(A_\tau^c)}\\
  &\leq
  \abs{F_\tau(t,x)}
  +
  2\varepsilon_\tau.
\end{align*}
Summing proves~\eqref{eq:sparse-retention-sum}.
\end{proof}

Thus the literal fixed-target existence question for nonconstant retained randomness is closed throughout the full C-prime regime. The remaining questions concern structured, non-sparse, or target-uniform coarsenings.

\subsection{The structured quadratic-Hessian points}

For the intrinsic quadratic-Hessian measures $\mu_\tau^{t,x}$, the characterization is consistent with every previously proved construction.

\paragraph{Raw-faithful / identity.}
For identity coarsening, the residual variation is the full raw total variation. The fixed smooth datum from~\cref{thm:raw-faithful-obstruction} has a divergent right-comb subseries. Thus~\cref{thm:residual-characterization} predicts non-$L^1$, exactly as the raw-faithful obstruction does.

\paragraph{Constant coarsening / C-prime.}
For the constant map,
\begin{equation*}
  V_\tau(\mathrm{const})
  =
  \abs{F_\tau(t,x)},
\end{equation*}
and Theorem C-prime proves summability throughout $4a<1$.

\subsection{Patchwise Gaussian bridges do not repair the raw obstruction}

\begin{lemma}[Right combs are one-edge patches]
\label{lem:right-comb-one-edge}
Under the convention that a patch is a maximal chain obtained by repeatedly following the left child, every patch of the right combs used in~\cref{thm:raw-faithful-obstruction} has length one.
\end{lemma}

\begin{proof}
At every internal vertex of a right comb the left child is a leaf, while the continuing internal child is the right child. A maximal left-child chain therefore stops at its first vertex.
\end{proof}

\begin{corollary}[Naive patchwise bridge coarsening fails]
\label{cor:bridge-coarsening-fails}
Fix $T>0$ and $\lambda\neq0$, and let $\phi_\varepsilon$ be the fixed smooth datum in~\cref{thm:raw-faithful-obstruction}. For every evaluation horizon $h\in(0,T]$ and every $x\in\Torus$, the naive coarsening which acts separately on each maximal-left patch by retaining its endpoint Gaussian and forgetting only internal Gaussian bridge coordinates has infinite first moment in the canonical coarsened conditional-barycenter class.
\end{corollary}

\begin{proof}
By~\cref{lem:right-comb-one-edge}, every patch on the right-comb obstruction family has length one. On a one-edge patch the normalized endpoint Gaussian is the original Gaussian mark, so the coarsening generates the same sigma-field as identity. If the unnormalized displacement is retained instead, the coordinate change is invertible once the edge duration is retained. In either version, total variation is unchanged on every obstruction cylinder. The divergent subseries from~\cref{thm:raw-faithful-obstruction} therefore survives.
\end{proof}

\subsection{Derivative clusters and the absolute-time patch bound}

For $m\geq1$, let
\begin{equation*}
  0<s_1<\cdots<s_m<t\leq T.
\end{equation*}
Given $G\in C^\alpha(\Torus)$ and $b_1,\ldots,b_m\in X_{\alpha,T}$, define
\begin{align*}
  \Xi_1&=b_1(s_1)P_{s_1}G,\\
  \Xi_r&=b_r(s_r)
  \partial_x^2P_{s_r-s_{r-1}}\Xi_{r-1},
  \qquad 2\leq r\leq m,
\end{align*}
and
\begin{equation}
  I_m[b_1,\ldots,b_m;G](t,x;\mathbf s)
  =
  \partial_x^2P_{t-s_m}\Xi_m(x).
  \label{eq:time-spine-integrand}
\end{equation}
Set
\begin{equation}
  \mathfrak P_m(\alpha,T)
  =
  \sup
  \frac{
    \displaystyle
    \sup_{t\leq T,x\in\Torus}
    \int_{0<s_1<\cdots<s_m<t}
    \abs{I_m(t,x;\mathbf s)}d\mathbf s
  }{
    \norm G_{C^\alpha}
    \prod_{j=1}^m\norm{b_j}_{X_{\alpha,T}}
  },
  \label{eq:time-patch-constant}
\end{equation}
and
\begin{equation}
  K_{\mathrm{time}}(\alpha,T)
  =
  \sup_{m\geq1}
  \mathfrak P_m(\alpha,T)^{1/m}.
  \label{eq:K-time}
\end{equation}

Every non-leaf planar binary tree has a unique root maximal-left patch. If its length is $m$, let $\sigma_1,\ldots,\sigma_m$ be its successive right subtrees. Then
\begin{equation}
  \tau
  \longleftrightarrow
  (m;\sigma_1,\ldots,\sigma_m),
  \qquad
  \abs\tau
  =
  m+\sum_{j=1}^m\abs{\sigma_j}.
  \label{eq:root-patch-decomposition}
\end{equation}
The time-spine coarsening retains the ordered branch times of this root maximal-left patch and integrates out every Gaussian/Brownian mark on that patch together with every continuous variable in the side subtrees. For target $(t,x)$ its pushforward signed measure has density
\begin{equation}
  \lambda^m
  I_m[F_{\sigma_1},\ldots,F_{\sigma_m};\phi'']
  (t,x;\mathbf s)d\mathbf s.
  \label{eq:time-spine-density}
\end{equation}

\begin{proposition}[Absolute-time derivative-cluster bound]
\label{prop:K-time-finite}
For every $0<\alpha<1$ and $T>0$, define
\begin{equation*}
  H_\alpha
  =
  \pa{\E\abs Z^{2\alpha}}^{1/2},
  \qquad
  D_{\alpha,T}
  =
  \frac{2T^{\alpha/2}}{\alpha},
  \qquad
  A_{\alpha,T}
  =
  H_\alpha D_{\alpha,T},
\end{equation*}
and
\begin{equation}
  K_{\mathrm{cl}}(\alpha,T)
  =
  4\max\set{
    1+A_{\alpha,T},
    2A_{\alpha,T}
  }.
  \label{eq:K-cluster}
\end{equation}
Then, for every $m\geq1$,
\begin{equation}
  \boxed{
  \begin{aligned}
  &\sup_{t\leq T,x\in\Torus}
  \int_{0<s_1<\cdots<s_m<t}
  \abs{I_m[b_1,\ldots,b_m;G](t,x;\mathbf s)}
  \,d\mathbf s\\
  &\qquad\leq
  2A_{\alpha,T}4^m
  (1+A_{\alpha,T})^{m-1}
  \norm G_{C^\alpha}
  \prod_{j=1}^m\norm{b_j}_{X_{\alpha,T}}\\
  &\qquad\leq
  K_{\mathrm{cl}}(\alpha,T)^m
  \norm G_{C^\alpha}
  \prod_{j=1}^m\norm{b_j}_{X_{\alpha,T}}.
  \end{aligned}
  }
  \label{eq:explicit-time-patch-bound}
\end{equation}
In particular,
\begin{equation}
  K_{\mathrm{time}}(\alpha,T)
  \leq
  K_{\mathrm{cl}}(\alpha,T)
  <\infty.
  \label{eq:K-time-explicit}
\end{equation}
No smallness assumption on a PDE parameter or datum is used in this estimate.
\end{proposition}

\begin{proof}
Write
\begin{equation*}
  K_r^{(k)}
  =
  \partial_x^{2k}P_r,
  \qquad
  M_Bf=Bf,
\end{equation*}
and let
\begin{equation*}
  c_{2k,\alpha}
  =
  \E\br{
    \abs{\He_{2k}(Z)}\abs Z^\alpha
  }.
\end{equation*}
The Hermite and multiplication-commutator estimates give
\begin{align}
  \norm{K_R^{(k)}f}_\infty
  &\leq
  c_{2k,\alpha}
  R^{-k+\alpha/2}
  [f]_{C^\alpha},
  \label{eq:cluster-Hermite-bound}\\
  \norm{[K_R^{(k)},M_B]f}_\infty
  &\leq
  c_{2k,\alpha}
  R^{-k+\alpha/2}
  [B]_{C^\alpha}
  \norm f_\infty.
  \label{eq:cluster-commutator-bound}
\end{align}
These are the only analytic inputs.

Set $s_{m+1}=t$ and
\begin{equation*}
  r_j=s_{j+1}-s_j,
  \qquad 1\leq j\leq m.
\end{equation*}
Then $r_j>0$, $\sum_{j=1}^m r_j<t$, and
\begin{equation*}
  s_1=t-\sum_{j=1}^m r_j.
\end{equation*}
The change of variables $(s_1,\ldots,s_m)\mapsto(r_1,\ldots,r_m)$ has unit Jacobian. Thus there is no additional integration variable associated with the initial heat interval. If $B_j=b_j(s_j,\cdot)$, then
\begin{equation}
  I_m
  =
  K_{r_m}^{(1)}M_{B_m}
  K_{r_{m-1}}^{(1)}M_{B_{m-1}}
  \cdots
  K_{r_1}^{(1)}M_{B_1}P_{s_1}G.
  \label{eq:time-patch-operator-word}
\end{equation}

Expand~\eqref{eq:time-patch-operator-word} repeatedly with
\begin{equation}
  K_R^{(k)}M_B
  =
  M_BK_R^{(k)}
  +
  [K_R^{(k)},M_B].
  \label{eq:cluster-expansion-identity}
\end{equation}
Passing a multiplier through the derivative block joins the current block to the next Hessian edge because
\begin{equation*}
  K_R^{(k)}K_r^{(1)}
  =
  K_{R+r}^{(k+1)}.
\end{equation*}
Choosing the commutator in~\eqref{eq:cluster-expansion-identity} terminates the current derivative cluster. Hence every resulting term partitions the $m$ derivative edges into consecutive clusters. If a term has $q$ clusters, then the $q-1$ cluster boundaries among the first $m-1$ multipliers may be chosen in
\begin{equation*}
  \binom{m-1}{q-1}
\end{equation*}
ways. At the innermost multiplier $B_1$ there are two terminal choices: the last cluster either ends in the commutator with $B_1$, or passes through $B_1$ and reaches $P_{s_1}G$. Thus the expansion contains exactly
\begin{equation}
  2\binom{m-1}{q-1}
  \label{eq:q-cluster-term-count}
\end{equation}
terms with $q$ clusters.

Consider one cluster with $\ell$ consecutive derivative edges and total duration $R$. For fixed $R$, the simplex of its $\ell$ positive edge durations has volume
\begin{equation*}
  \frac{R^{\ell-1}}{(\ell-1)!}.
\end{equation*}
If the cluster ends at a multiplier, use~\eqref{eq:cluster-commutator-bound}; if it is the innermost cluster and reaches $G$, use~\eqref{eq:cluster-Hermite-bound} together with
\begin{equation*}
  [P_{s_1}G]_{C^\alpha}
  \leq
  [G]_{C^\alpha}.
\end{equation*}
After the internal subdivision of the cluster is integrated, its derivative factor is therefore bounded by
\begin{equation}
  \frac{c_{2\ell,\alpha}}{(\ell-1)!}
  R^{-1+\alpha/2}.
  \label{eq:one-cluster-factor}
\end{equation}
Every multiplier appears exactly once, either through its supremum norm or through its $C^\alpha$ seminorm at the end of a cluster, and hence costs at most $\norm{b_j}_{X_{\alpha,T}}$.

By Cauchy--Schwarz and Hermite orthogonality,
\begin{equation*}
  c_{2\ell,\alpha}
  \leq
  H_\alpha\sqrt{(2\ell)!}.
\end{equation*}
Moreover,
\begin{equation*}
  \frac{\sqrt{(2\ell)!}}{(\ell-1)!}
  =
  \ell\sqrt{\binom{2\ell}{\ell}}
  \leq
  \ell2^\ell
  \leq
  4^\ell.
\end{equation*}
Thus
\begin{equation}
  \frac{c_{2\ell,\alpha}}{(\ell-1)!}
  \leq
  H_\alpha4^\ell.
  \label{eq:cluster-geometric-Hermite}
\end{equation}

Now fix a term whose cluster lengths are $\ell_1,\ldots,\ell_q$, with total durations $R_1,\ldots,R_q$. Since $\sum_i\ell_i=m$, multiplying~\eqref{eq:one-cluster-factor} and~\eqref{eq:cluster-geometric-Hermite} gives the coefficient $H_\alpha^q4^m$. The cluster totals satisfy $R_i>0$ and $\sum_iR_i<t\leq T$. Hence
\begin{align*}
  \int_{\substack{R_i>0\\\sum_iR_i<t}}
  \prod_{i=1}^qR_i^{-1+\alpha/2}
  \,d\mathbf R
  &\leq
  \prod_{i=1}^q
  \int_0^T R^{-1+\alpha/2}\,dR\\
  &=
  D_{\alpha,T}^q.
\end{align*}
Consequently each $q$-cluster term is bounded in absolute time integral by
\begin{equation*}
  4^mA_{\alpha,T}^q
  \norm G_{C^\alpha}
  \prod_{j=1}^m\norm{b_j}_{X_{\alpha,T}}.
\end{equation*}
Using~\eqref{eq:q-cluster-term-count} and summing over $q$ gives
\begin{align*}
  \mathfrak P_m(\alpha,T)
  &\leq
  2\,4^m
  \sum_{q=1}^m
  \binom{m-1}{q-1}A_{\alpha,T}^q\\
  &=
  2A_{\alpha,T}4^m
  (1+A_{\alpha,T})^{m-1}.
\end{align*}
This is the first inequality in~\eqref{eq:explicit-time-patch-bound}.

If $A_{\alpha,T}\leq1$, then
\begin{equation*}
  2A_{\alpha,T}4^m(1+A_{\alpha,T})^{m-1}
  \leq
  [4(1+A_{\alpha,T})]^m.
\end{equation*}
If $A_{\alpha,T}\geq1$, then
\begin{equation*}
  2A_{\alpha,T}4^m(1+A_{\alpha,T})^{m-1}
  \leq
  (8A_{\alpha,T})^m.
\end{equation*}
The definition~\eqref{eq:K-cluster} therefore gives the second inequality in~\eqref{eq:explicit-time-patch-bound} and hence~\eqref{eq:K-time-explicit}.
\end{proof}

\begin{corollary}[Target-uniform time-spine $L^1$ representation]
\label{thm:time-spine}
Fix $0<\alpha<1$, $T>0$, $\lambda\in\R$, and $\phi\in C^{2+\alpha}(\Torus)$. Let
\begin{equation*}
  X=X_{\alpha,T},
  \qquad
  M=\norm{P_\cdot\phi''}_X,
  \qquad
  a=\abs\lambda C_{\cD}(\alpha,T)M,
\end{equation*}
and let $K_{\mathrm{time}}(\alpha,T)$ be defined by~\eqref{eq:K-time}. Put
\begin{equation*}
  b
  =
  \abs\lambda K_{\mathrm{time}}(\alpha,T)M,
\end{equation*}
and
\begin{equation*}
  C(a)
  =
  \frac{1-\sqrt{1-4a}}{2a},
  \qquad
  C(0)=1.
\end{equation*}
Assume
\begin{equation}
  \boxed{
  4a<1,
  \qquad
  bC(a)<1.
  }
  \label{eq:time-spine-smallness}
\end{equation}
Then the single time-spine coarsening rule described above works for every observation point $(t,x)\in[0,T]\times\Torus$. More precisely, for every such target,
\begin{equation}
  \sum_{\tau\in\cT}
  \norm{(\cC_{\tau}^{\mathrm{time},t,x})_\#
  \mu_\tau^{t,x}}_{\TV}
  \leq
  \frac{M}{1-bC(a)}
  <\infty.
  \label{eq:time-spine-TV-sum}
\end{equation}
The canonical coarsened importance sampler is therefore an unbiased $L^1$ representation of the C-prime solution $z_*(t,x)$ for every target. The ordered branch-time vector on the root maximal-left patch is retained and affects the estimator nontrivially. No Gaussian/Hermite or Brownian mark is retained by this time-spine rule.
\end{corollary}

\begin{proof}
For $\tau\leftrightarrow(m;\sigma_1,\ldots,\sigma_m)$,~\eqref{eq:time-spine-density} and~\cref{prop:K-time-finite} give
\begin{align*}
  V_\tau(\cC_\tau^{\mathrm{time}})
  &\leq
  \abs\lambda^mK_{\mathrm{time}}^mM
  \prod_{j=1}^m\norm{F_{\sigma_j}}_X\\
  &\leq
  Mb^m
  \prod_{j=1}^m a^{\abs{\sigma_j}},
\end{align*}
where~\eqref{eq:Cprime-tree-bound} is used in the second line. Summing independently over the side subtrees gives
\begin{equation*}
  \sum_{\tau\in\cT}
  V_\tau(\cC_\tau^{\mathrm{time}})
  \leq
  M+M\sum_{m\geq1}[bC(a)]^m
  =
  \frac{M}{1-bC(a)}.
\end{equation*}
The bound is uniform in $(t,x)$. The total mass of every coarsened skeleton measure remains $F_\tau(t,x)$, and $4a<1$ gives the absolutely convergent C-prime sum. Theorem~\ref{thm:residual-characterization} therefore yields the claimed $L^1$ representation at every target.

To see that the retained time is nondecorative, take the one-vertex tree and $\phi''(x)=\cos x$. At $x=0$ the retained-time density contains
\begin{equation*}
  \partial_x^2P_{t-s}[(P_s\cos)^2](0)
  =
  -2e^{-2t+s},
\end{equation*}
which depends nontrivially on $s$.
\end{proof}

The distinction between~\cref{prop:K-time-finite,thm:time-spine} is logical. The derivative-cluster estimate is an analytic statement valid for arbitrary inputs in the stated H\"older classes and uses no smallness. Smallness enters only when the estimate is inserted into the infinite tree sum defining the representation.

If
\begin{equation*}
  \theta
  =
  \frac{K_{\mathrm{time}}(\alpha,T)}
  {C_{\cD}(\alpha,T)},
\end{equation*}
then the second condition in~\eqref{eq:time-spine-smallness} is
\begin{equation}
  \frac\theta2
  \pa{1-\sqrt{1-4a}}<1.
  \label{eq:time-spine-theta-condition}
\end{equation}
For $\theta\leq2$ it follows automatically from $4a<1$; for $\theta>2$ it is equivalent to
\begin{equation*}
  a<\frac{\theta-1}{\theta^2}.
\end{equation*}
Thus the time-spine corollary has a potentially stronger smallness condition than C-prime, and the exact strengthening depends on the valid operator constants.

The three structured points are therefore values of the same invariant:
\begin{equation*}
  \text{identity/raw-faithful: divergent residual variation},
\end{equation*}
\begin{equation*}
  \text{time-spine: summable residual variation under~\eqref{eq:time-spine-smallness}},
\end{equation*}
\begin{equation*}
  \text{constant/C-prime: summable residual variation under }4a<1.
\end{equation*}

\subsection{What remains open}

The exact characterization closes the arbitrary fixed-target existence problem for skeleton-preserving coarsenings, but it does not make the structured representation problem trivial.

\begin{enumerate}[label=\textup{(\roman*)}]
\item Find a non-sparse coarsening with a fixed geometric description which is $L^1$ throughout the full C-prime regime.
\item Extend a target-uniform structured construction, such as the time-spine rule, to the full C-prime regime with quantitative function-space control.
\item Given a prescribed retained sigma-field or computational budget, optimize the residual variation
\begin{equation*}
  \int
  \abs{\E[R_\tau\mid\mathcal G_\tau]}
  d\nu_\tau.
\end{equation*}
\item Determine whether a more global Gaussian coarsening, beyond patchwise bridge averaging, controls the one-edge obstruction family without collapsing all useful Gaussian information.
\item Formulate and analyze cross-skeleton coarsenings, where the skeleton label itself may be averaged and cancellation can occur between different tree shapes.
\end{enumerate}

The mathematical principle of the paper can now be stated exactly: cancellation before absolute values is the removal of signed variation by conditional averaging, and $L^1$ integrability is equivalent to summability of the signed variation which survives.
