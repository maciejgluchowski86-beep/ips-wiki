% BLURB A. Why conditioning on the skeleton helps
%
% Reader question:
%   We have fixed the successful-interaction skeleton. What information is still
%   unresolved, and what does its locality buy us?
%
% Job:
%   Say first what G_T fixes and what it leaves unresolved. It fixes all
%   successful interactions and hence the patch decomposition up to time T. It
%   does not reveal the local information deliberately omitted from the
%   skeleton. In particular, deaths inside patches are not recorded, and for a
%   recorded outgoing interaction the skeleton does not say whether it was a
%   split or a birth.
%
%   The fixed patch boundaries restrict this remaining randomness. Depending on
%   the boundary types, they may force an interaction kind or exclude a death.
%   These restrictions involve only one patch at a time. State the payoff and
%   stop there: conditional on G_T, the unresolved randomness factorizes over
%   patches.
%
% Keep out:
%   Sigma_P, alpha(P), Con(P), averaging, cancellations, and the formal
%   factorization theorem. Blurbs B--D make the local law and factorization
%   precise; Blurbs E--F explain what is averaged and why.
% ============================================================================

Conditioning on~$\mathcal G_T$ fixes the successful interactions and hence the
patch decomposition up to time~$T$. It leaves unresolved the local information
that was omitted from the skeleton. In particular, deaths inside patches are
not recorded, and for a recorded outgoing interaction the skeleton does not say
whether it was a split or a birth. The fixed patch boundaries restrict this
remaining randomness: depending on the boundary types, they may force the
interaction kind or exclude deaths. These restrictions involve only one patch
at a time. Consequently, conditional on~$\mathcal G_T$, the unresolved
randomness factorizes over the patches.

% ============================================================================
% BLURB B. Reference law on one patch
%
% Reader question:
%   Before imposing the boundary constraints, what is the local law of the
%   unresolved marks on one patch, and how do those marks determine the
%   one-site process X^P?
%
% Job:
%   Fix a patch P. Define a reference law for the information on its site that is
%   not contained in the skeleton. Inside the patch, this consists of the
%   outgoing Poisson marks on the patch site. If the initial boundary is
%   outgoing, also restore the split/birth kind omitted from that boundary
%   record. The reference law is simply the restriction of the original
%   graphical construction to this local information.
%
%   Define Sigma_P^circ, Sigma_P, and the reference law P_P and expectation E_P.
%   Then define X^P directly under this reference law as the one-site active
%   process generated by the local marks. State its initial value and update
%   rules. Compatibility with the fixed patch boundaries is imposed only in
%   Blurb C.
%
% Formatting:
%   Do not introduce an isolated display merely to abbreviate i(P), s(P), e(P),
%   and S(P). Keep notation economical.
% ============================================================================

Fix a patch~$P$, and write~$i=i(P)$,~$s=s(P)$,~$e=e(P)$, and~$S=S(P)$.
We first define a reference law for the information in the patch~$P$, that is not
revealed by the skeleton. Inside the patch, the outgoing marks from~$i$ are
\begin{equation*}
\Sigma_P^\circ
=
\cb{(i,u,\gamma,R)\in I:s<u<e}.
\end{equation*}
For each~$R$, the~$(\delta,R)$ and~$(\beta,R)$ marks in~$(s,e)$ are independent
Poisson processes with rates~$\delta_i(R)$ and~$\beta_i(R)$, respectively.

It remains to specify the information at the initial boundary. If
$\mathsf X(P)=\mathsf I$, the boundary is incoming, so there is no outgoing
mark from~$i$ to add and we set~$\Sigma_P=\Sigma_P^\circ$. If
$\mathsf X(P)=\mathsf O$, the boundary record specifies the target~$S$ but not
whether the interaction is a split or a birth. Let
$\alpha(P)\in\cb{\delta,\beta}$ denote its kind, independent of
$\Sigma_P^\circ$, with
\begin{equation}
\label{eq:patch-initial-kind-law}
\pP_P\bb{\alpha(P)=\delta}
=
\frac{\delta_i(S)}{\delta_i(S)+\beta_i(S)},
\qquad
\pP_P\bb{\alpha(P)=\beta}
=
\frac{\beta_i(S)}{\delta_i(S)+\beta_i(S)}.
\end{equation}
In this case,
\begin{equation*}
\Sigma_P
=
\Sigma_P^\circ\cup\cb{(i,s,\alpha(P),S)}.
\end{equation*}
Together, the interior Poisson marks and, when present, the random initial kind
define the reference patch law~$\pP_P$. Write~$\E_P$ for expectation under
$\pP_P$.

The marks in~$\Sigma_P$ determine a one-site process~$X^P\in\cb{0,1}$, where
$X_u^P=1$ means that the patch site is active at time~$u$. Its initial value is
\begin{equation*}
X_s^P
=
\pw{1}{\mathsf X(P)=\mathsf I}
{\ind\cb{\alpha(P)=\beta}}{\mathsf X(P)=\mathsf O}.
\end{equation*}
The interior marks are then read in chronological order. When~$X_{u-}^P=1$, a
$\delta$-mark sets~$X_u^P=0$ and a~$\beta$-mark leaves~$X_u^P=1$; when
$X_{u-}^P=0$, either mark leaves~$X_u^P=0$. Between marks,~$X^P$ is constant.
For a finite patch with terminal label~$\mathsf E$, set~$X_e^P=X_{e-}^P$.

Not every realization under~$\pP_P$ is compatible with the patch boundaries
fixed by the skeleton. A non-death mark inside patch would be a
successful interaction whenever the patch site is active immediately before
it, and would therefore create additional patches. Hence such
marks can only occur with~$X_{u-}^P=0$. If the terminal boundary is outgoing, the
recorded interaction must itself be successful, so~$X_{e-}^P=1$. There is no
additional endpoint condition for an incoming or end boundary. We therefore
define the consistency event
\begin{equation*}
\operatorname{Con}(P)
=
\cb{
\begin{aligned}
X_{u-}^P=0
&\quad\text{for every }(i,u,\gamma,R)\in\Sigma_P^\circ\\[-0.2em]
&\quad\text{with }R\neq\varnothing
\end{aligned}
}
\cap
\pw{\cb{X_{e-}^P=1}}{\mathsf Y(P)=\mathsf O}
{\Omega_P}{\mathsf Y(P)\in\cb{\mathsf I,\mathsf E}},
\end{equation*}
where~$\Omega_P$ is the sample space of the patch law. Depending on
the boundary types, this condition can determine the hidden initial interaction
kind or exclude deaths inside the patch.

For almost every patch arising from the graphical construction,
$\pP_P\bb{\operatorname{Con}(P)}>0$. Its consistent patch law is
\begin{equation*}
\pP_P^{\mathrm{con}}(\cdot)
=
\pP_P\bb{\,\cdot\,\middle|\,\operatorname{Con}(P)},
\end{equation*}
and~$\E_P^{\mathrm{con}}$ denotes expectation under this law.

% BLURB D. Conditional factorization
%
% Reader question:
%   Do the one-patch laws above actually give the conditional law of the
%   graphical construction once the successful-interaction skeleton is fixed?
%
% Job:
%   State the answer directly before the theorem: conditional on G_T, different
%   patches are independent and each has the consistent one-patch law. Explain
%   why this is the useful output of the preceding construction: conditional
%   expectations of products of patch-local quantities reduce to products of
%   one-patch expectations.
%
%   State Theorem [Patch factorization] and equation (patch-factorization).
%
% Proof organization:
%   State the calculation before introducing its notation. Compute the joint law
%   of the skeleton record and the patch variables relative to a reference
%   measure on possible record lists; set the patch test functions to one to get
%   the marginal law of the skeleton; divide the two densities to obtain the
%   conditional law. Before applying Mecke, prove that a proposed record list is
%   exactly the successful-interaction skeleton iff every associated patch is

% ============================================================================

The one-patch laws above describe exactly the randomness left after the
successful-interaction skeleton is fixed. Conditional on~$\mathcal G_T$,
different patches are independent and each patch has its consistent law. Thus a
conditional expectation of a product of patch-local quantities reduces to a
product of one-patch expectations.

\begin{theorem}[Patch factorization]
\label{thm:patch-factorization}
Fix~$T<\infty$. Conditional on~$\mathcal G_T$, the variables~$\Sigma_P$ are
independent, and the conditional law of~$\Sigma_P$ is
$\pP_P^{\mathrm{con}}$ for each~$P\in\mathcal P_T$. Equivalently, for bounded
measurable functions~$f_P$ such that either all~$f_P$ are nonnegative or the
product on the left below is integrable,
\begin{equation}
\label{eq:patch-factorization}
\CE{
\prod_{P\in\mathcal P_T}f_P\bb{\Sigma_P}
}{\mathcal G_T}
=
\prod_{P\in\mathcal P_T}
\E_P^{\mathrm{con}}\Cb{f_P\bb{\Sigma_P}}.
\end{equation}
\end{theorem}

\begin{proof}
Write~$G_T=(Y_0,\mathcal I_T)$, so~$\mathcal G_T=\sigma(G_T)$. We compute the
joint law of~$G_T$ and the patch variables relative to a reference measure on
possible successful-interaction records. Setting all patch test functions equal
to~$1$ then gives the marginal law of~$G_T$, and the quotient of the two
densities gives the conditional law.

By Lemma~\ref{lem:dual-local-finiteness}, the positive-time records in~$G_T$
almost surely form a finite chronological list
\begin{equation*}
g=\bb{(i_k,t_k,S_k)}_{k=1}^n,
\qquad
0<t_1<\cdots<t_n\leq T,
\end{equation*}
where~$\varnothing\neq S_k\subseteq N(i_k)$ and
$i_k\in A\cup\bigcup_{\ell<k}S_\ell$. We call the discrete sequence
$((i_k,S_k))_{k=1}^n$ admissible when these conditions hold. On the disjoint
union of all such record lists, define
\begin{equation}
\label{eq:patch-record-reference-measure}
m_T(dg)
=
\sum_{n\geq0}
\sum_{\substack{((i_k,S_k))_{k=1}^n\\\text{admissible}}}
\ind\cb{0<t_1<\cdots<t_n\leq T}
\prod_{k=1}^n
\bb{\delta_{i_k}(S_k)+\beta_{i_k}(S_k)}
\,dt_1\cdots dt_n.
\end{equation}
Thus~$m_T$ is the Poisson intensity measure for a proposed list of
nonempty-target interaction records, with the split and birth kinds suppressed.

Fix such a record list~$g$, and let~$\mathcal P_T(g)$ be the patch family it
defines. The interactions in~$g$ are exactly the successful interactions up to
time~$T$ if and only if every~$P\in\mathcal P_T(g)$ satisfies
$\operatorname{Con}(P)$. Indeed, suppose first that every patch is consistent. Then there are no successful interactions that originate from interior of a patch, and every interaction with record in~$g$ is successful because the consistency event for its source patch ensures it happens at an active site. Thus~$g$ is exactly the list of records of successful interactions. Conversely, if~$g$ is the
successful-interaction record, then each~$X^P$ is the restriction of the global
active indicator to its patch, so every patch is consistent.

We can now compute the joint law. For nonnegative measurable~$h$ and~$f_P$, the
multivariate Mecke formula~\cite[Theorem~4.4]{LastPenrose2017}, applied to the
ordered nonempty-target marks, gives
\begin{equation}
\label{eq:patch-factorization-mecke}
\E_A\Cb{
h(G_T)
\prod_{P\in\mathcal P_T}f_P\bb{\Sigma_P}
}
=
\int h(g)
\prod_{P\in\mathcal P_T(g)}
\E_P\Cb{
f_P\bb{\Sigma_P}\ind_{\operatorname{Con}(P)}
}
\,m_T(dg).
\end{equation}
Here a record~$(i,t,S)$ has combined intensity
$\bb{\delta_i(S)+\beta_i(S)}\,dt$, while conditional on this record its hidden
kind has the law in~\eqref{eq:patch-initial-kind-law}. After these records are
fixed, the remaining marks on distinct patch intervals are independent with the
reference laws~$\pP_P$. The consistency indicators impose exactly the condition
proved above that~$g$ is the successful-interaction record.

Setting~$f_P=1$ in~\eqref{eq:patch-factorization-mecke} gives the marginal law
of the skeleton record,
\begin{equation*}
\pP_A\bb{G_T\in dg}
=
\prod_{P\in\mathcal P_T(g)}
\pP_P\bb{\operatorname{Con}(P)}
\,m_T(dg).
\end{equation*}
Therefore, for~$\pP_A\circ G_T^{-1}$-almost every~$g$, the Radon--Nikodym
quotient of the joint density in~\eqref{eq:patch-factorization-mecke} by this
marginal density is
\begin{align*}
\E_A\Cb{
\prod_{P\in\mathcal P_T}f_P\bb{\Sigma_P}
\,\middle|\,G_T=g
}
&=
\prod_{P\in\mathcal P_T(g)}
\frac{
\E_P\Cb{f_P\bb{\Sigma_P}\ind_{\operatorname{Con}(P)}}
}{
\pP_P\bb{\operatorname{Con}(P)}
}
\\
&=
\prod_{P\in\mathcal P_T(g)}
\E_P^{\mathrm{con}}\Cb{f_P\bb{\Sigma_P}}.
\end{align*}
This proves~\eqref{eq:patch-factorization} for nonnegative factors and
identifies the conditional law. The integrable signed case follows from this
conditional-law statement.
\end{proof}

% BLURB E. Patch contributions and proof of the representation
%
% Reader question:
%   How does patch factorization turn the Feynman--Kac duality into the patch
%   representation of P_t chi_A?
%
% Job:
%   Recall the Feynman--Kac random variable whose expectation is P_t chi_A.
%   Explain that Theorem [Patch factorization] can be applied once this random
%   variable is written as a product of quantities depending on individual
%   patches. Split its sign, potential integral, and terminal monomial over the
%   patch decomposition. Package these pieces into F(P) and F(z,P), and define
%   C(P) and C(z,P) as their expectations under the consistent patch laws.
%
%   State the resulting pathwise product and prove
%   Theorem~\ref{thm:patch-representation} by conditioning on G_t, applying patch
%   factorization, taking expectation, and using monomial duality. Keep explicit
%   boundary-type formulas in the appendix.
% ============================================================================

We now return to the goal of this section, the representation of
$P_t\chi_A(\eta)$ in Theorem~\ref{thm:patch-representation}. For fixed
$t\geq0$ and~$\eta\in\Omega$, write the random variable in the Feynman--Kac
duality as
\begin{equation*}
Z_t^\eta
=
\sigma_t
\exp\bb{\int_0^tV(A_u)\,du}
\chi_{A_t}(\eta),
\qquad
P_t\chi_A(\eta)=\E_A\Cb{Z_t^\eta}.
\end{equation*}
Theorem~\ref{thm:patch-factorization} applies once~$Z_t^\eta$ is written as a
product of factors over patches. We therefore split its
sign, Feynman--Kac integral, and terminal monomial over the patch decomposition.

Each successful nonempty-target interaction contributes its sign to the
outgoing patch beginning at its source. Empty-target deaths have positive sign
because~$a_i^\delta(\varnothing)=c_i^0(\varnothing)\geq0$. Thus define
\begin{equation*}
\sigma(P)
=
\pw{+}{\mathsf X(P)=\mathsf I}
{\sigma_{i(P)}^{\alpha(P)}\bb{S(P)}}{\mathsf X(P)=\mathsf O},
\end{equation*}
so that
\begin{equation*}
\sigma_t
=
\prod_{P\in\mathcal B_t}\sigma(P)
\prod_{P\in\mathcal E_t}\sigma(P).
\end{equation*}
Since~$V(A_u)=\sum_{i\in A_u}V_i$, the patch intervals split the potential
integral, while the end patches describe the active set at time~$t$. Hence
\begin{align*}
\int_0^tV(A_u)\,du
&=
\sum_{P\in\mathcal B_t}
V_{i(P)}\int_{s(P)}^{e(P)}X_u^P\,du
+
\sum_{P\in\mathcal E_t}
V_{i(P)}\int_{s(P)}^tX_u^P\,du,
\\
\chi_{A_t}(\eta)
&=
\prod_{P\in\mathcal E_t}
\eta\bb{i(P)}^{X_t^P}.
\end{align*}

These are exactly the pieces that enter the local patch factors. For a full
patch~$P\in\mathcal P$, set
\begin{equation*}
F(P)
=
\sigma(P)
\exp\bb{
V_{i(P)}\int_{s(P)}^{e(P)}X_u^P\,du
}.
\end{equation*}
When~$e(P)=\infty$, the exponential is interpreted as the limit over finite
upper endpoints. For an end patch~$P\in\mathcal E_t$ and~$z\in[0,1]$, include
the terminal factor and set
\begin{equation*}
F(z,P)
=
\sigma(P)
\exp\bb{
V_{i(P)}\int_{s(P)}^tX_u^P\,du
}
z^{X_t^P}.
\end{equation*}
The preceding identities now give the pathwise factorization
\begin{equation}
\label{eq:pathwise-patch-factorization}
Z_t^\eta
=
\prod_{P\in\mathcal B_t}F(P)
\prod_{P\in\mathcal E_t}F\bb{\eta\bb{i(P)},P}.
\end{equation}
Patch factorization tells us to average each local factor under its consistent
patch law. We therefore define
\begin{equation*}
C(P)=\E_P^{\mathrm{con}}\Cb{F(P)},
\qquad
C(z,P)=\E_P^{\mathrm{con}}\Cb{F(z,P)}.
\end{equation*}
Since~$X_t^P\in\cb{0,1}$, the map~$z\mapsto C(z,P)$ is affine. Explicit
formulas for~$C(P)$ and~$C(z,P)$ for each boundary type are given in
Appendix~\ref{app:contribution-formulas}.

\begin{proof}[Proof of Theorem~\ref{thm:patch-representation}]
By~\eqref{eq:fk-integrability}, we may condition
\eqref{eq:pathwise-patch-factorization} on~$\mathcal G_t$.
Theorem~\ref{thm:patch-factorization} gives
\begin{equation*}
\CE{Z_t^\eta}{\mathcal G_t}
=
\prod_{P\in\mathcal B_t}C(P)
\prod_{P\in\mathcal E_t}C\bb{\eta\bb{i(P)},P}.
\end{equation*}
Taking expectation and using Theorem~\ref{thm:monomial-duality} yields
\eqref{eq:patch-representation}. Integrating this identity with respect to an
arbitrary initial law~$\mu$ gives
\begin{equation*}
(\mu P_t)(\chi_A)
=
\E_A\Cb{
\prod_{P\in\mathcal B_t}C(P)\,
\mu\bb{
\prod_{P\in\mathcal E_t}C\bb{\eta\bb{i(P)},P}
}
},
\end{equation*}
which is~\eqref{eq:patch-representation-general-law}. This proves both
assertions of Theorem~\ref{thm:patch-representation}.
\end{proof}

% BLURB F. Product initial laws and the role of patch averaging
%
% Reader question:
%   How does the general representation simplify for product initial laws, and
%   what has the patch averaging accomplished before patch positivity is imposed?
%
% Job:
%   Specialize the general-initial-law formula to Bernoulli product measures
%   using the distinct end-patch sites and affinity of C(z,P). Then make the
%   averaging concrete: all empty-target death marks inside a patch are
%   integrated out, while at an outgoing initial boundary the target is fixed
%   and the hidden split/birth kind is averaged. Opposite split/birth signs can
%   therefore cancel inside C(P) or C(z,P). Explain that patch positivity makes
%   every completed bulk contribution C(P) nonnegative, so no negative sign
%   remains in the bulk product; end contributions retain their terminal
%   argument and require separate sign control.
% ============================================================================

For a Bernoulli product measure~$\mu_{\mb p}$ with
$\mu_{\mb p}\bb{\eta(i)=1}=p_i$, the sites~$i(P)$,
$P\in\mathcal E_t$, are distinct. Hence independence of the spins at these
sites and~$z\mapsto C(z,P)$ being affine gives
\begin{equation*}
\mu_{\mb p}\bb{
\prod_{P\in\mathcal E_t}C\bb{\eta\bb{i(P)},P}
}
=
\prod_{P\in\mathcal E_t}
C\bb{p_{i(P)},P}.
\end{equation*}
Therefore
\begin{equation}
\label{eq:patch-representation-product-law}
(\mu_{\mb p}P_t)(\chi_A)
=
\E_A\Cb{
\prod_{P\in\mathcal B_t}C(P)
\prod_{P\in\mathcal E_t}C\bb{p_{i(P)},P}
}.
\end{equation}

The patch expectations average exactly the local information omitted from the
skeleton. In particular, the contribution of all  deaths is integrated out. If a patch begins with an outgoing boundary,
the skeleton fixes its target~$S(P)$ but not whether that interaction was a
split or a birth, so this hidden kind, and the sign flip it may carry, is also averaged under the consistent
patch law. When a split and birth with the same target carry opposite signs,
their contributions cancel in~$C(P)$ or~$C(z,P)$. Patch positivity requires
that, after these local averages, every completed patch satisfy~$C(P)\geq0$.
Thus no negative sign remains in the bulk product, only the end contributions. These still depend on their terminal argument and require separate sign control.
