% BLURB A. Why conditioning on the skeleton helps
%
% Reader question:
%   We have defined the successful-interaction skeleton and G_T. What does
%   conditioning on this information buy us?
%
% Job:
%   Connect directly to the previous subsection. Once the skeleton is fixed,
%   all patch boundaries are fixed. What remains unobserved consists of the
%   Poisson marks on the individual site intervals and, at an outgoing initial
%   boundary, the hidden interaction kind. Explain that these pieces are local
%   to individual patches. The only further requirement is that the local
%   history on each patch be compatible with the already fixed skeleton.
%
%   Give the reader the mechanism before any local notation:
%       independent local graphical randomness
%       -> require compatibility with the fixed patch boundaries
%       -> independent conditioned patch laws.
%
% Keep out:
%   Sigma_P, alpha(P), Con(P), and the formal factorization theorem. Do not use
%   administrative roadmap language.
% ============================================================================

Conditioning on~$\mathcal G_T$ fixes every successful interaction, and hence
every patch boundary, up to time~$T$, while leaving the rest of the graphical
construction unobserved. The omitted randomness is local to individual patches:
it consists of the Poisson marks on the patch site between its boundaries and,
when the patch begins with an outgoing interaction, the interaction kind that
the skeleton deliberately omitted. These local pieces arise from independent
Poisson processes on disjoint patch intervals. The fixed skeleton imposes only
local restrictions on them: the omitted marks must not create additional
successful interactions inside a patch, and an outgoing terminal boundary must
occur while its source is active. Consequently, the conditional law is obtained
by conditioning the original one-patch graphical law on this local
compatibility condition, independently for each patch.
