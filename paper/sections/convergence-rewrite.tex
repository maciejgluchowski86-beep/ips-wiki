% ============================================================================
% ESTIMATE 1. SPATIAL CONFINEMENT
%
% Reader question:
%   How much contribution can come from histories that travel far from A before
%   the cut time T?
%
% Job:
%   Define Cone_T, E_T^R, and rho_A(T,R). State the spatial-confinement estimate
%   for both W_t^mu and W. Explain in ordinary IPS language that the confined
%   contribution is identified with the zero-boundary finite-volume dynamics,
%   and finite propagation makes rho_A(T,R) small when R grows linearly with T.
%
% Appendix:
%   The confined-interaction identity and finite-propagation proof remain in the
%   technical appendix.
% ============================================================================

% ============================================================================
% ESTIMATE 2. A SUCCESSFUL INTERACTION AFTER T
%
% Reader question:
%   Why are histories with a successful interaction after T exponentially
%   suppressed by the uniform pure deaths?
%
% Job:
%   Define L_{T,t} and L_T. Introduce the ancestry of the first successful
%   interaction after T. The geometric fact needed is that its predecessor
%   patches ending in outgoing interactions form a chain from time 0 to the
%   interaction time, so their lifetimes add to u > T. State this ancestry fact
%   as a supporting lemma or short lemma immediately before the late-interaction
%   estimate. Then use the exact death factor along the chain to obtain
%   exp(-epsilon T).
%
% Hierarchy:
%   The ancestry lemma supports the late-interaction estimate; do not present it
%   as a fourth error of equal status.
% ============================================================================

% ============================================================================
% ESTIMATE 3. RELAXATION AFTER THE LAST INTERACTION
%
% Reader question:
%   If no successful interaction occurs after T, why does the remaining
%   dependence on the initial law disappear as t-T grows?
%
% Job:
%   On L_{T,t}, the patch structure is fixed after T and only the end patches
%   continue. State directly that the nonconstant part of each affine end
%   contribution decays exponentially under the empty-neighbour refresh
%   dynamics. On E_T^R there are at most |R| end patches. State the resulting
%   bound
%       (1+|R|) exp(-epsilon(t-T)).
%
% Appendix:
%   Exact continuation identities, consistency normalizers, and explicit
%   boundary-type calculations belong in the appendix. Keep only enough
