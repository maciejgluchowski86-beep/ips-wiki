\section{Patch positivity and centered-moment order}
\label{sec:patch-positivity}

Theorem~\ref{thm:patch-representation} gives the representation
\begin{equation*}
(\mu P_t)(\chi_A)
=
\E_A\Cb{
\prod_{P\in\mathcal B_t}C(P)\,
\mu\bb{
\prod_{P\in\mathcal E_t}C\bb{\eta\bb{i(P)},P}
}
}.
\end{equation*}
The patch contributions appearing here are defined in
Section~\ref{sec:representation}, where the representation is proved. To obtain
inequalities from this formula, we need to control the sign of patch contributions. We call the
system patch-positive when~$C(P)\geq0$ for every bulk patch~$P$. We show that this condition is
equivalent to explicit inequalities on the coefficients of the flip rates.
Bulk positivity does not determine the sign of an end contribution, since
$C(z,P)$ still depends on its terminal argument~$z$. For each site~$i$, we
therefore determine the smallest~$p_i\in[0,1]$ for which
$C(p,P)\geq0$ for every end patch based at~$i$ and call this value the patch
threshold~$p_i^\star$. These two sign controls are what allow the patch
representation to yield the moment comparisons proved later in the section.

\subsection{Coefficient criterion}
\label{subsec:positivity-criterion}

% ============================================================================
% BLURB A. Reduce patch positivity to the boundary cases
%
% Reader question:

%   checked from the local rates?
%
% Job:
%   Fix a site i and a bulk patch P based at i, and write
%   Delta=e(P)-s(P). Briefly remind the reader that the two boundary labels say
%   whether the initial and terminal boundaries are incoming or outgoing. Use
%   the explicit contribution formulas from Appendix~\ref{app:bulk-formulas}.
%
%   Show first that every patch whose initial boundary is incoming has a
%   nonnegative contribution. State the consequence clearly: only patches whose
%   initial boundary is outgoing can impose conditions on the coefficients of
%   the flip rates.
%
% Keep out:
%   Derivation of the patch-contribution formulas, interpretation of the
%   coefficient inequalities, and end-patch positivity.
% ============================================================================

Our goal in this subsection is to determine when~$C(P)\geq0$ for every bulk
patch using only the coefficients of the flip rates, thereby proving the
coefficient criterion in Theorem~\ref{thm:patch-positivity-order}. Fix a
site~$i$ and a bulk patch~$P$ based at~$i$, and write
$\Delta=e(P)-s(P)$. Since~$P$ is a bulk patch, both of its boundary interactions
occur before the observation time. Thus
$\mathsf X(P),\mathsf Y(P)\in\cb{\mathsf I,\mathsf O}$, where~$\mathsf I$
means that the boundary interaction is incoming at~$i$ and~$\mathsf O$ that it
is outgoing from~$i$.

The formulas in Appendix~\ref{app:bulk-formulas} give~$C(P)$ for each of these
boundary types. If the initial boundary is incoming, then
\begin{equation*}
C(P)
=
\begin{cases}
\displaystyle
\frac{\psi_i(\Delta,1)}{\varphi_i(\Delta)},
&\mathsf X(P)\mathsf Y(P)=\mathsf{II},
\\[1em]
e^{V_i\Delta},
&\mathsf X(P)\mathsf Y(P)=\mathsf{IO}.
\end{cases}
\end{equation*}
Recall that an empty-target death has positive sign, since
$\delta_i(\vn)=c_i^0(\vn) = c_i(\mb{0})\geq0$. From the definitions in
Appendix~\ref{app:contribution-formulas},
$\psi_i(\Delta,1)\geq0$,~$\varphi_i(\Delta)>0$, and the exponential is
positive too. Hence every bulk patch with an incoming initial boundary has a
nonnegative contribution. Therefore only patches with an outgoing initial boundary can impose conditions on the coefficients of the flip rates.

% ============================================================================
% BLURB B. Outgoing terminal boundary gives the first inequality
%
% Reader question:
%   What restriction comes from a patch whose initial and terminal boundaries
%   are both outgoing?
%
% Job:
%   Let the initial outgoing interaction have nonempty target S. For an OO
%   patch, quote the formula
%       C(P)=sigma_i^beta(S)e^{V_i Delta}
%   together with
%       beta_i(S)sigma_i^beta(S)=-c_i^0(S)-c_i^1(S).
%   Since beta_i(S)>=0 and the exponential is positive, conclude that all such
%   contributions are nonnegative exactly when
%       c_i^0(S)+c_i^1(S)<=0.
%   Note that this condition does not depend on the patch length Delta.
%
% Reader takeaway:
%   The OO family contributes exactly the first coefficient inequality.
% ============================================================================

Let now the initial boundary be outgoing, with nonempty target~$S$. If the
terminal boundary is also outgoing, then Appendix~\ref{app:bulk-formulas} gives
\begin{equation*}
C(P)=\sigma_i^\beta(S)e^{V_i\Delta},
\qquad
\beta_i(S)\sigma_i^\beta(S)
=-c_i^0(S)-c_i^1(S).
\end{equation*}
Thus the sign of an~$\mathsf{OO}$ contribution is the sign of
$-c_i^0(S)-c_i^1(S)$. Consequently, all such contributions are nonnegative
exactly when
\begin{equation}
\label{eq:patch-positivity-first-inequality}
c_i^0(S)+c_i^1(S)\leq0
\qquad\text{for every nonempty }S\subseteq N(i).
\end{equation}
