\ABSTRACT{%
Kinetically constrained spin models have monotone constraints: adding vacancies
can enable updates but cannot block them. Nevertheless, their dynamics need not
be monotone in the usual configuration order. Motivated by this phenomenon, we
introduce patch-positive spin systems, a class inspired by KCSMs but not
restricted to the KCSM form. We show that every patch-positive system preserves
an order on probability laws defined by centered moments, so that a
monotonicity principle survives even when configuration monotonicity fails.
Patch positivity also yields comparisons between certain non-monotone dynamics,
including comparison with the system obtained by removing
environment-independent~$1\to0$ transitions. On interaction graphs of
polynomial growth, a uniform positive rate of such transitions implies
convergence from a broad class of initial laws to a common invariant measure;
if the associated patch threshold profile, determined by the local rates, is
at most~$1/2$, the invariant measure is unique and convergence is uniform over
all initial configurations. The main tool is an exact graphical representation
obtained by conditioning a signed Feynman--Kac dual on a coarse interaction
record and averaging the remaining local randomness over spacetime patches.
FA-1f and the biased annihilating branching process illustrate the criterion.}
