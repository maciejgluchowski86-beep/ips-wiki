% Partial-derivative helper:  \der{x}  -> d/dx ;  \der{x}{k} -> d^k/dx^k
% PORTABILITY: the previous body called the expl3 conditional
% \tl_if_blank:nTF OUTSIDE an \ExplSyntaxOn..\ExplSyntaxOff group, where
% ':' and '_' are not letters, so on a modern TeX Live it tokenises as the
% undefined \tl followed by stray text (-> "Undefined control sequence" /
% "Missing $"). TL2019's older standalone xparse happened to tolerate it
% because the branch was never expanded.  Re-expressed without expl3 so the
% preamble parses identically on every TeX Live.  Public behaviour for the
% real call patterns \der{x} and \der{x}{k} is unchanged.
\NewDocumentCommand{\der}{m g}{%
  \IfNoValueTF{#2}
    {\frac{\partial}{\partial #1}}
    {\frac{\partial^{#2}}{\partial #1^{#2}}}%
}
