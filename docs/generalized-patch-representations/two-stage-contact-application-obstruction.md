# Two-stage contact process: a natural application where typed patch positivity fails

> **Research-branch page.** This page exists only on `research/generalized-patch-representations`. It records current project mathematics and is not published on `main`.

## Model

The two-stage contact process has local states

\[
0=\text{vacant},\qquad1=\text{juvenile},\qquad2=\text{adult},
\]

with transitions

\[
0\to1 \text{ at rate }\lambda n_2(x),
\qquad
1\to2 \text{ at rate }\gamma,
\]

\[
1\to0 \text{ at rate }1+\delta,
\qquad
2\to0 \text{ at rate }1.
\]

This is a genuine three-state single-site replacement IPS: juveniles must mature before reproducing, and the juvenile state cannot be removed without changing the dynamics.

The model was selected from the literature before any patch-positivity calculation.

## Typed dual specialization

Using vacancy as reference state, for each neighbour `j` put

\[
\tau_j=\{j\mapsto2\}.
\]

The adult-driven birth rate has tensor coefficient

\[
\widehat c^{0\to1}(\tau_j)=\lambda.
\]

The corresponding nonempty outgoing dual row is

\[
\boxed{
\mathbf a_{1,\tau_j}=(\lambda,-\lambda,-\lambda).}
\]

The empty-target rows are

\[
\mathbf a_{1,\emptyset}=(0,-(1+\delta+\gamma),0),
\]

\[
\mathbf a_{2,\emptyset}=(0,\gamma,-1).
\]

Hence the signed interior transfer is

\[
K=
\begin{pmatrix}
0&0&0\\
0&-(1+\delta+\gamma)&0\\
0&\gamma&-1
\end{pmatrix}.
\]

Every successful record reveals source type `1` and target type `2` while hiding one of three post-source outcomes `0,1,2`, with signs `+,-,-`.

## Cemetery is genuinely present

An incoming target of type `2` is compatible with a local target-patch state `0` or `2`. If that patch currently carries type `1`, the merge conflicts and the typed dual enters cemetery.

Such a type-1 state can occur from initial typed data, from an earlier hidden outcome `1`, or from the empty-target backward retyping generated by juvenile maturation. Thus the killed/noncemetery factorization is genuinely operative in this natural model.

## Realized negative bulk patch

The hidden outcome `1` has positive absolute mass whenever `lambda>0`. A later successful record at the same source again requires pre-source type `1`. Therefore the same-source outgoing-to-outgoing descriptor is realized.

Its numerator is

\[
N_{OO}(t)
=\mathbf a_{1,\tau_j}e^{tK}e_1^T.
\]

Writing

\[
a=1+\delta+\gamma,
\]

for `a>1`,

\[
\boxed{
N_{OO}(t)
=-\lambda\left[
e^{-at}
+\gamma\frac{e^{-t}-e^{-at}}{a-1}
\right]<0.}
\]

If `a=1`, then `gamma=delta=0` and

\[
N_{OO}(t)=-\lambda e^{-t}<0.
\]

The killed-reference denominator is strictly positive. Hence

\[
\boxed{
\text{the two-stage contact process is not typed patch positive for any }\lambda>0.}
\]

At the exact gate point

\[
\lambda=\gamma=\delta=1,
\qquad e^{-t}=1/2,
\]

one obtains

\[
N_{OO}=-5/16,
\qquad D_{OO}=5/16,
\qquad C_{OO}=-1.
\]

## Catalytic-birth no-go

The same calculation yields a local obstruction useful beyond this model.

Suppose a positive nonempty target mode appears in a physical transition

\[
0\to r
\]

but the same target mode does not occur in transitions into `r` from active source states. Then the indicator-basis typed row has

\[
a_r^r(\tau)<0.
\]

If the source-`r` successful record can occur again after hidden outcome `r`, the zero-length limit of a realized `OO` patch is negative.

A spatial SIRS model has the same structure and the same obstruction. Thus this no-go covers a broad family of catalytic contact/epidemic birth mechanisms.

## Relation to known two-stage duality

The two-stage process already has classical multitype duality and strong convergence theory due to Krone and Foxall, and Krone's duality is included in general pathwise-duality frameworks.

The typed killed-patch representation is different: it hides a three-valued source outcome and explicitly encounters typed cemetery conflicts. In this application, however, the bulk positivity layer fails before that representation can yield a new patch-positive comparison or convergence theorem.

This is therefore a **negative application result**, not a new duality theorem for the two-stage contact process.
