# Path coupling for Glauber dynamics

## Criterion

Let $(\Omega,d)$ be a finite configuration space whose metric is generated by a set of adjacent pairs: for every $x,y$ there is a path

\[
x=z_0,z_1,\ldots,z_m=y
\]

such that

\[
d(x,y)=\sum_{k=0}^{m-1}d(z_k,z_{k+1}).
\]

Suppose that for every adjacent pair $(x,y)$ one can couple one step of the Markov chain, producing $(X_1,Y_1)$, so that for some $\beta<1$,

\[
\mathbb E[d(X_1,Y_1)\mid X_0=x,Y_0=y]
\leq \beta d(x,y).
\]

The path-coupling construction extends these local couplings along a shortest path and yields the same expected contraction for arbitrary initial pairs. If the metric has minimum nonzero distance $1$ and diameter $D$, then after $t$ steps

\[
\Pr(X_t\neq Y_t)
\leq \mathbb E d(X_t,Y_t)
\leq D\beta^t,
\]

so the total-variation mixing time is at most of order

\[
\frac{\log(D/\varepsilon)}{1-\beta}.
\]

For single-site Glauber dynamics, the natural adjacent pairs are configurations differing at one site and $d$ is often Hamming or weighted Hamming distance.

## Mechanism

A direct coupling proof appears to require a coupling for every pair of configurations. Path coupling uses the geometry of the state space to reduce this to local pairs. Couple each adjacent pair along a shortest path, and combine the resulting endpoint distributions by the triangle inequality for the associated transportation distance. The expected contraction on each edge then adds along the path.

Dyer--Goldberg--Jerrum implement this in Section 3.1 for random-update Glauber dynamics. Their proof of Lemma 17 joins two arbitrary spin configurations by successively replacing coordinates, so consecutive configurations differ at one site. A dependency matrix $R$ controls how a single disagreement can create disagreements at other sites. The random-update matrix is

\[
R^\dagger=\frac{n-1}{n}I+\frac1nR.
\]

If $\|R\|\leq\mu<1$, Lemma 16 gives $\|R^\dagger\|\leq1-(1-\mu)/n$. Applying path coupling then gives the quantitative mixing bound of Lemma 17.

This is methodologically distinct from [Dobrushin's observable-influence argument](dobrushin-influence-contraction.md) even when the same matrix verifies both. Path coupling asks for a contractive coupling only on neighboring state pairs and can use a problem-specific metric; Dobrushin contraction starts from conditional influence coefficients and propagates coordinate oscillations of observables.

## Representative IPS use

The checked source applies path coupling to finite spin systems with Glauber updates. In Section 4 it analyzes graph-coloring Glauber dynamics by bounding the dependency matrix with graph structure. Example 2 considers heat-bath Glauber dynamics for proper colorings of a $\Delta$-regular graph with $2\Delta+1$ colors, where the relevant dependency matrix has spectral radius $\Delta/(\Delta+1)<1$. The local one-disagreement calculation is therefore enough to control mixing of the full configuration chain.

The original Bubley--Dyer paper also advertises applications to graph coloring, the antiferromagnetic Potts model and the hard-core lattice gas, which explains the technique's early connection to spin systems.

## Limitations

Path coupling requires a useful path metric and a strictly contractive local coupling. The ordinary Hamming metric can fail even when a weighted metric, block metric, multi-step coupling or a different argument succeeds. Hard constraints may make a single disagreement branch into several before it can disappear, giving expected distance at least one despite eventual mixing.

The method is primarily a finite-state quantitative mixing tool. An $O(n\log n)$ finite-volume bound does not automatically imply a particular infinite-volume ergodicity or spectral-gap statement without a separate uniform finite-to-infinite argument. Conversely, failure of one chosen path metric is not evidence of nonergodicity.
